## HK20 Outer Header — XOR обфускация

```python
KEY_XOR = b"\xBA\xCD\xBC\xFE\xD6\xCA\xDD\xD3\xBA\xB9\xA3\xAB\xBF\xCB\xB5\xBE"

def decode_header(data: bytes) -> bytes:
    return bytes(data[i] ^ KEY_XOR[(i + (i >> 4)) & 0xF]
                 for i in range(len(data)))
```

Ключ публично известен (hiktools, PyPI).

### Уязвимость 1 — Поддельная «контрольная сумма» (CWE-326)

В заголовке есть поле `checksum`. При анализе выяснилось:
```
checksum == header_length    ← одно и то же число в двух форматах
```

Это не хеш и не CRC. Любые поля заголовка (`device_class`, `oem_code`, версия) можно подменить — устройство не проверяет целостность.

## AES-256-ECB шифрование тела

### Уязвимость 2 — ECB режим (CWE-327)

ECB шифрует каждый 16-байтный блок **независимо**. Следствие: одинаковые блоки плейнтекста дают одинаковые блоки шифртекста.

```
Шифртекст(block_A) == Шифртекст(block_B)  →  plaintext_A == plaintext_B
```

Без знания ключа можно построить **карту нулевых блоков**:

```python
# Найти "сигнатурный блок" (шифр нулей) без ключа
from collections import Counter

with open('digicap.dav', 'rb') as f:
    f.seek(124)   # пропустить заголовки
    body = f.read()

blocks = [body[i:i+16] for i in range(0, len(body), 16)]
cnt = Counter(blocks)
zero_block = cnt.most_common(1)[0][0]   # самый частый блок = шифр нулей
# → b'\xb3\x11\x02\x0e...' встречается 40 065 раз = 640 KB нулей
```

---

## Карта плейнтекста (без ключа!)

| Смещение | Плотность нулей | Интерпретация |
|----------|-----------------|---------------|
| `0x00007C – 0x5FFFFC` | 0% | Сжатое ядро или rootfs |
| `0x0060007C – 0x006C007C` | 55–28% | Граница flash-раздела |
| `0x0070007C – 0x00CFFF7C` | 0% | Второй раздел |
| `0x00D0007C – 0x00D8007C` | 47–14% | Вторая граница раздела |
| `0x00D8007C – конец` | 0% | Основное тело приложений |

626 KB нулевого плейнтекста картировано **без AES-ключа**.

## Уязвимость 3 — Нет подписи (CWE-354)

Нет HMAC, нет RSA, нет Ed25519. При наличии AES-ключа:

```
1. Расшифровать тело
2. Внедрить backdoor / изменить конфиг
3. Перешифровать с тем же ключом
4. Записать обратно в digicap.dav
5. Загрузить на устройство через веб-интерфейс
→ Устройство примет прошивку как легитимную
```

## Уязвимость 4 — Plaintext footer (CWE-200)

```
293 786 737 mod 16 = 5
```

Последние 5 байт файла **не зашифрованы** (AES-ECB не дополняет последний неполный блок):

```python
with open('digicap.dav', 'rb') as f:
    f.seek(-5, 2)
    tail = f.read()
# tail = b'\x61\x74\x69\x6f\x6e' = "ation"
# → хвост copyright-строки "...corporation"
```
